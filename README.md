# Listas de Programação Web (PHP)

**IFAC · Técnico em Informática para Internet (TIPI)** · 2º ano · 2022

Listas de exercícios de Programação Web resolvidas em PHP: cada `php/lista-NN.php` responde uma lista (de 01 a 19), com formulários e resultado na mesma página.

| Pasta | |
|---|---|
| `index.html` | Página inicial com links para as listas |
| `php/` | Listas 01 a 19 e estilos (`css/`) |
| `js/` | Scripts de apoio (lista 08) |

## Como rodar

```bash
php -S localhost:8000
# abra http://localhost:8000
```
